# BlastDodger
Blast Dodger (filler name) is a fast-fast paced 2d endless-runner built in Unity for the web, where you remotely pilot disposable mining drones across the molten, machinery-scarred world of Krneal. Using a simple four-button control scheme (three lane-switch buttons and a fire button) you dodge jutting pipes, blast open mineral cases, and collect fuel, ammo, and valuable or while navigating a narrow industrial channel. As a contractor for a massive mining consortium, you select timed contracts to fulfill across multiple runs, earning money for cosmetic upgrades and future defensive gear. Runs end when you crash or run out of fuel, but the grimy industrial atmosphere, escalating speed, and steady contract progression keep each attempt tense, rewarding, and re-playable. 
 

# Core Gameplay Loop (Rough Sketch)
* Scan the 3 lanes ahead 
* Choose a lane 
* Decide whether to shoot or dodge
* Collect Resources
* Udate resource meters
* React to increasing speed
* Repeat until crash or fuel depletion
